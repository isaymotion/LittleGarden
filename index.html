YOUR DATA, YOURS TO KEEP

Tools and backup

▤

Export a polished PDF

Create a printable report for a week, month, or year. Includes every transaction, charts, and spending insights. Choose a clean spreadsheet-style report or a more visual garden-themed design.

All transactions in the selected period will be included. In the print dialog, choose “Save as PDF” to save a PDF file.

↗

Export records

Save a full JSON backup (it includes your Pay me QR codes) or a spreadsheet-friendly CSV file.

↙

Restore a backup

Import a JSON backup or CSV. You can replace records or merge them.

Install on this device

Add Little Garden to your home screen so it opens like an app and works offline.

♡

Private by design

Your entries stay in this browser using local storage. No account or server is required. Export backups regularly, especially before clearing browser data.

Daily rhythm

Use the date field to log expenses as you go. Your daily chart and monthly summary update automatically.
